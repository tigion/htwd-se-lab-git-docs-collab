== Worum geht es

Im Praktikum wollen wir uns mit den Themen *Versionsverwaltung*, *Docs-as-Code*
und *Zusammenarbeit* beschäftigen.

Die Aufgaben bieten eine Einführung in die Handhabung folgender Werkzeuge:

- *Git* - Versionsverwaltung von Softwareprojekten
- *AsciiDoc* - textbasierte Generierung von technischen Dokumentationen
- icon:github[] *GitHub* - Online-Plattform für die Versionsverwaltung mit Git
  und die Zusammenarbeit im Team

== Hinweise & Einschränkungen

- Die Praktikumsaufgaben können in den *Computer-Laboren* der Fakultät unter
  icon:linux[] Linux bzw. icon:windows[] Windows oder auf dem *eigenen Rechner*
  bearbeitet werden.
- *Linux-Labore*: Nutzereinstellungen bleiben erhalten und werden in den
  jeweiligen Home- bzw. Profil-Verzeichnissen gespeichert.
- *Windows-Labore*: Es werden keine Nutzerprofile gespeichert. Die
  Konfiguration von Git und das Anpassen der Werkzeuge (Erweiterungen,
  Einstellungen) muss nach jedem Anmelden neu vorgenommen werden.
- *Eigener Rechner*: Unter link:install-and-config/[Installation
  & Konfiguration] finden Sie Hinweise, wie Sie die benötigten Programme auf
  Ihrem Rechner einrichten.

TIP: Nutzen Sie für die ersten beiden Praktika die Laborrechner, statt Ihres
eigenen Rechners, um sich mit den eingesetzten Tools vertraut zu machen.

IMPORTANT: Daten im Temp-Laufwerk `T:` unter Windows werden nach dem Abmelden
gelöscht. Diese müssen vorher in Ihr Home-Laufwerk `U:` (`Z:`) verschoben oder
anderweitig gesichert werden.

=== AsciiDoc, Asciidoctor

[NOTE]
--
*AsciiDoc* is a plain text markup language for writing technical content. It’s
packed with semantic elements and equipped with features to modularize and
reuse content. AsciiDoc content can be composed using a text editor, managed in
a version control system, and published to multiple output formats. +
- http://asciidoc.org
--

* https://asciidoc.org/[AsciiDoc] - offizielle Webseite
* https://asciidoctor.org/[Asciidoctor] - is a fast, open source text processor
  and publishing toolchain for converting AsciiDoc content to HTML5, DocBook,
  PDF, and other formats. Asciidoctor is written in Ruby and runs on all major
  operating systems.
** https://docs.asciidoctor.org/asciidoc/latest/[AsciiDoc Language Documentation]
** https://docs.asciidoctor.org/asciidoc/latest/syntax-quick-reference/[AsciiDoc Syntax Quick Reference]
** https://asciidoctor.org/docs/asciidoc-writers-guide/[AsciiDoc Writer’s Guide]
* Videos:

   - Alexander Schwartz (29.03.2020)
** icon:film[] https://www.youtube.com/watch?v=jiEz69wYLtM[Evolving real-world
