=== Software Engineering II

// tag::07-git-advanced[]
.🎓 Lernziele von Teil 7 - Git Advanced
[%collapsible]
====
****
* Änderungen und Versionen mit *Git-Kommandos* verwalten
** Versionen untersuchen und vergleichen (`git diff`, `git log`, `git switch`)
** Änderungen verwerfen (`git restore`, `git clean`)
** Änderungen (temporär) wegspeichern (`git stash`)
** Versionen zurücknehmen mit `git reset` (Historie umschreiben) oder `git revert` (Historie erhalten)
* Versionen ändern oder zusammenfassen
** Ändern der letzten Version mit `git commit --amend`
** Zusammenfassen und Umstrukturieren von Versionen mit `git rebase -i`
* Risiken beim Verändern von veröffentlichten Versionen kennen und vermeiden
****
====
// end::07-git-advanced[]
